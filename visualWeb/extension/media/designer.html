POST API에서 입력 UI 생성

OpenAPI 목록을 불러온 뒤 POST API를 선택하세요. 선택한 POST의 JSON requestBody를 읽어 입력 필드와 캔버스 컴포넌트를 만듭니다. 기존 입력 필드와 입력 컴포넌트는 교체됩니다.

입력 컴포넌트의 API 필드 이름을 JSON 키로 사용합니다. Grid 내부 버튼은 클릭한 행을 보내고, 외부 버튼은 지정한 Grid의 선택 행을 보냅니다. 경로에 {id}를 사용하면 요청 데이터의 id로 치환합니다.
